# Rock, Paper, Scissors Game

A fun and interactive Rock, Paper, Scissors game built with HTML, CSS, and JavaScript. Play against the computer, track your scores, and enjoy smooth animations!

## Features

- **Classic Gameplay**: Choose Rock, Paper, or Scissors and play against the computer.
- **Score Tracking**: Keeps track of your wins, losses, and draws.
- **Persistent Scores**: Scores are saved in your browser's localStorage and persist after refreshing the page.
- **Visual Enhancements**: Emojis for each choice (✊ Rock, 🖐️ Paper, ✌️ Scissors).
- **Animations**: Smooth CSS animations including button hover effects and a bounce animation for results.
- **Responsive Design**: Works well on different screen sizes.

## How to Play

1. Click on one of the three buttons: Rock, Paper, or Scissors.
2. The computer will randomly choose its move.
3. The result will be displayed, and your score will update accordingly.
4. Try to get the highest win count!

### Game Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Same choices result in a draw

## Installation

No installation required! This is a simple web-based game.

1. Clone or download the repository.
2. Open `index.html` in your web browser.

## Usage

- Open `index.html` in any modern web browser.
- Start playing by clicking the choice buttons.
- Your scores will be automatically saved and displayed.

## Technologies Used

- **HTML**: Structure of the game.
- **CSS**: Styling and animations.
- **JavaScript**: Game logic, score tracking, and localStorage management.
